## [3.0.0] - 2026-08-19

### Changed
- **Renamed:** Project formally renamed from Universal Research Pipeline (URP) to **Vivechak (विवेचक)** (*vi-* + *√vic* + *-aka* = "the discerning analyst").
- **Core Principles Overhaul:** Replaced rigid dogma with 8 empirically grounded principles (Context Architecture Law, Reversibility-Calibrated Rigor, GRADE-aligned Evidence Grading, 5-Block Prompt Anatomy, Wardley Evolution Composition, Dual-Audience Artifacts, Staged Triangulation, Structured Falsification).
- **Prompt Anatomy:** Replaced 8-section XML prompts and artificial expert personas with streamlined 5-block prompt structure (BRIEF, SCOPE, APPROACH, DELIVERABLE, FORMAT).
- **Adaptive Complexity Scaling:** Replaced static session quotas with 8-dimension scoring (0–24) across 4 tiers (Tier 0 to Tier 3).
- **Phase 0 Gate:** Replaced rigid 9-step gate with Two-Track System (Track A Fast-Track for Two-Way Doors; Track B 9-Step Gate + Gary Klein Premortem for One-Way Doors).
- **Dual-Mode Pipeline Generator:** Added Single-Session (IDE agents) and Split Generation (web chat) workflows in `GENERATOR.md`.
- **Self-Contained Workspace:** Projects now copy 4 operational templates into `research/templates/` for complete agentic autonomy.

### Added
- **Logo Asset:** Minimalist geometric prism logo (`docs/assets/logo.jpg`) symbolizing evidence separation.
- **Sealed Meta-Research Corpus:** 14 primary deep-research sessions, 10 ADR verdicts, and 31 empirical evidence nodes in `meta-research/`.
- **Operational Templates:**
  - `templates/DECISIONS.template.md` (YAML frontmatter ADR schema)
  - `templates/CONFLICT-RESOLUTION.template.md` (ACH trade-off matrix)
  - `templates/FOUNDING-ARCHITECTURE.template.md` (Map-Reduce synthesis to FAD)
  - `templates/PHASE-0-GATE.template.md` (Two-track pre-codebase exit gate)
- **Examples:** End-to-end sample pipeline walkthrough in `examples/SAMPLE-PIPELINE.md`.
- **Governance:** Added `LICENSE` (MIT), `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `VERSION`, and GitHub community templates.

This repository is the **Universal Meta-Framework, Engine, and Generator** for creating pre-development research pipelines across any domain or project.

Consolidating the research DNA of **6 landmark projects**:

- **Yugm:** 22-session 3-tier pipeline, Prompt Library, Compose+Build (~40/60) formula, Markdown Artifact Contract.
- **Vivah (Soodh):** Unbiased discovery sessions (U1–U8), 47-gap domain analysis.
- **Portfolio Website:** 16-session decision framework (`DP-01` to `DP-16`), Universal Synthesis (`DP-USYN`).
- **Forge & Rachak:** Zero-bias prompt independence, bias-resistance directives, sovereignty filtering.
- **Pramedha & Gemmra:** 72-module research planning, data pipeline ADR validation.

## 3. How to Use for a New Project (The 3-Step Workflow)

### Step 1: Generate the Pipeline
Open a new AI session, copy the prompt from **`META-PROMPT-GENERATOR.md`**, fill in your new project's parameters (Name, Domain, Vision, Constraints, Unique Engines), and execute.

### Step 2: Run the Research Sessions
1. Save the generated `RESEARCH-PIPELINE.md` and `PROMPT-LIBRARY.md` into your new project's `research/` folder.
2. Run **Tier 1 (Problem & Landscape)** in parallel (web search ON; optionally triangulated across Claude + ChatGPT + Gemini).
3. Run **Tier 2 (Solution & Architecture)** to make stack decisions using Grade A–E evidence.
4. Resolve conflicts via Checkpoints (`CHK-01`).
5. Run **Tier 3 (Implementation Blueprints)** sequentially to generate schemas and pure algorithms.
6. Run **SYN-01** to synthesize the **Founding Architecture Document (FAD)** and challenge load-bearing assumptions.

### Step 3: Pass the Phase 0 Gate
Verify the checklist in **`templates/PHASE-0-GATE.template.md`**, initialize `DECISIONS.md` and `ARCHITECTURE.md`, and create your first git commit.

## 4. Core Pillars Summary

| Pillar | Methodology | Source |
|---|---|---|
| **Zero Premature Code** | Absolute ban on writing application code prior to synthesis | All projects |
| **Triangulation Engine** | Multi-model consensus & divergence analysis | Triyantra |
| **Evidence Grading** | Grade A (Specs/Code) to Grade E (AI Speculation) | Triyantra |
| **Compose + Build** | ~40% Composed Primitives + ~60% Proprietary Domain Logic | Yugm |
| **Bias Resistance** | Naming explicit cognitive biases in prompts & prompt independence | Forge / Rachak |
| **Temporal Grounding** | Pinned live-year versions & deprecation audits | Yugm / Portfolio |
| **Universal Synthesis** | Topic-based consolidation + FAD blueprint | Portfolio / Yugm |
| **Phase 0 Gate** | Strict exit criteria before code repository initialization | Yugm / Triyantra |
